When a game runs too fast or too slow

Boxer gives each game a CPU speed chosen for it, and most games need no adjustment.

If a game still runs too slowly, press Cmd ⌘+I to bring up the CPU Inspector and enable “Optimize for newer games.” This lets Boxer emulate the processor in a faster way, at the cost of being less exact: turn it off again if the game crashes or misbehaves.

To set a game’s speed by hand, edit its cpu_cycles setting — see Customising DOSBox settings. Higher values emulate a faster processor; many older games rely on a slow one and will misbehave if the speed is raised.
